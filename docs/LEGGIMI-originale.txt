PRIMO COLLEGAMENTO
Admin -> Password.0 -> Collega file esistente -> classifica.json incluso.
Autorizzare lettura e scrittura e verificare Salvataggio automatico attivo.
Il pacchetto include un JSON vuoto; non sono stati recuperati vecchi risultati.
Il riferimento al file usa un nuovo archivio browser, quindi collegare il file
al primo utilizzo di questa versione.
Ogni nuovo record aggiorna il file collegato. Aspettare Classifica salvata
prima di chiudere: non serve un ulteriore salvataggio manuale serale.
Alla riapertura si tenta il recupero del riferimento in IndexedDB. Se il
permesso è ancora valido, lettura automatica; altrimenti Admin -> Riattiva /
Salva o nuova selezione del file. Il permesso può essere richiesto di nuovo.

COMPATIBILITÀ E RECUPERO
Provare Chrome/Edge desktop. Il salvataggio diretto da HTML aperto con doppio
clic dipende dal browser e dai permessi: il gioco verifica le API disponibili.
Se non disponibile, usare da Admin importazione e backup manuali.
Importare non autorizza la scrittura sul file: occorre collegarlo o crearne uno.
Scarica backup produce una copia; non sovrascrive automaticamente il file
collegato e non azzera l'avviso di record non salvati nel file principale.
In errore i record restano in memoria: riprovare da Admin o esportare prima
di chiudere. Nessun messaggio di successo se la scrittura non riesce.
Usare una sola scheda/postazione per file. Il controllo delle modifiche esterne
non rende il programma un database multiutente. La scrittura locale non
conferma che Dropbox abbia completato la sincronizzazione.
Non usare navigazione privata per ricordare il collegamento al file.
